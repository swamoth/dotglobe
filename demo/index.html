A globe in 17 kB.

A dot-matrix globe on WebGL2. Markers, arcs, labels, heat maps, and a day-night line. No three.js.

Get started See the layers
17.5 kBcore, gzipped
0.2 msCPU for each frame
0frames while idle
31xsmaller than react-globe.gl

Ten thousand markers cost one texture.

A marker lives in a data texture, not a vertex buffer. One draw call covers every marker. Rings pulse from a place.

globe.setMarkers([{ lat, lng, size: 0.012, shape: 'ring' }]);
globe.setRings([{ lat, lng, maxRadius: 9, period: 3 }]);

Arcs that draw themselves in.

An arc is an instanced ribbon that keeps its width in pixels. It can appear, travel a dash, and erase itself. A path follows the surface.

globe.setArcs([{ startLat, startLng, endLat, endLng, appear: 900 }]);
globe.setPaths([{ points, stroke: 1.5 }]);

Data on the dots.

Bin places onto the lattice. Each dot grows and takes a color from a ramp. Bars rise from a place.

globe.setDotData(binPoints(places, 20000), 20000);
globe.setStyle({ dataColor: ['#6b7280', '#7aa2f7', '#ff7a45'] });

Regions, borders, and a heat map.

Blur places into a heat map. Outline any GeoJSON area. Hover to name the country under the pointer.

globe.setTint(heatmap(places, 1024, 512), 1024, 512);
globe.setPaths(geometryPaths(country.geometry));

Labels that hide when they should.

A label is an HTML element that follows a place. It hides behind the globe and yields to a label with a higher priority. Click the globe to send an arc.

globe.setLabels([{ lat, lng, text: 'London', priority: 2 }]);
globe.on('click', (hit) => /* hit.lat, hit.lng, hit.country */);

Night falls where the sun says.

Put the sun over a place, or over where it is right now. Add a graticule. Nothing here moves on its own when the OS asks for less motion.

globe.setSun(new Date());
globe.setStyle({ night: 0.85, graticule: 15 });

Install

One package, no dependency. A land mask ships with it, so the first globe needs no data.

npm install dotglobe
import { createGlobe } from 'dotglobe';
import { land } from 'dotglobe/land';

const globe = createGlobe(canvas, { autoRotate: 6 });
globe.setLand(...await land());
globe.setMarkers([{ lat: 51.5, lng: -0.13, color: '#ff7a45' }]);
